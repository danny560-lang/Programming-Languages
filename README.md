# Programming Languages

Activities exploring how programming languages are designed and how they behave, written in Python.

| Folder | What it is |
|---|---|
| `parser/` | A recursive-descent arithmetic interpreter built from a BNF/EBNF grammar, with a parse tree diagram |
| `lexical-analyzer/` | Demonstrations of typing and lexical scope |
| `dynamic-scoping/` | Simulates dynamic scoping with an explicit call-frame stack, for comparison with Python's lexical scoping |
| `paradigm-comparison/` | The same problem solved three ways: imperative, object-oriented and functional |

Each folder includes a screenshot of the program output.
